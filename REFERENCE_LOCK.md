# ULTRON — Reference Lock

## Non-negotiable visual direction
- The user's uploaded reference image is the MASTER visual reference.
- Do NOT invent an alternative robot face or redesign the interface.
- The ULTRON face must be recreated to match the reference as closely as technically possible: metallic construction, facial proportions, eye treatment, jaw structure, glow, and central holographic presentation.
- The surrounding interface must follow the reference composition: same overall layout hierarchy, center placement, side panels, command area, holographic/core structure, spacing, visual density, and dark/cyan cinematic HUD language.
- Do NOT add personal design ideas or change the composition without explicit user approval.

## Build order
1. Match the ULTRON face and central composition first.
2. Match the surrounding UI layout and proportions.
3. Match interaction states and animations.
4. Only then continue to backend/agent functionality.

## Accuracy rule
- Never claim the interface is "exactly the same" unless it has actually been visually verified against the user's reference.
- The reference image is the source of truth for future ULTRON UI work.
