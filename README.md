# ULTRON AI

A personal, permission-aware desktop AI assistant inspired by cinematic AI interfaces.

## Current stage

Phase 1 establishes the futuristic command interface and project foundation.

### Planned modules

- AI brain and task planner
- Voice input and speech output
- Computer-control tools
- Browser automation
- File and application tools
- Local memory
- Permission and confirmation layer
- Command/activity console

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Safety principle

ULTRON will require explicit confirmation before consequential actions such as deleting files, sending messages, making purchases, changing security settings, or other high-impact operations.
